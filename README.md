# 🚗 Car Sales Analytics Dashboard | Power BI

An interactive **Power BI analytics solution** built to evaluate car sales performance, vehicle trends, pricing, and regional sales across India.

The dashboard transforms raw sales data into **actionable business insights** using **Power Query, DAX, data modeling, and interactive visual analytics**.

## 🎯 Business Focus

The dashboard provides insights into:

* 🚘 **Sales Performance** — total sales, cars sold & average selling price
* 🏷️ **Brand & Model Analysis** — identify top-performing vehicles
* ⛽ **Vehicle Preferences** — fuel type, transmission & body type
* 📅 **Sales Trends** — monthly and yearly performance
* 📍 **Regional Performance** — city and state-level sales
* 🗺️ **Geographic Analysis** — India state-wise sales using Shape Map

---

## 🧩 Dashboard Pages

**01 — Sales Overview**
Executive-level KPIs, brand performance, sales trends, fuel type and transmission analysis.

**02 — Vehicle Insights**

**03 — Sales & Regional Insights**
City and state-level performance with an interactive India sales map and top-selling models.

## ⚙️ Data & Technical Implementation

### Data Preparation

* Cleaned and transformed raw car sales data using **Power Query**
* Standardized data types and categorical fields
* Prepared date, sales and vehicle attributes for analysis

### Data Modeling & DAX

* Created analytical measures using **DAX**
* Built calculated fields for sales analysis
* Created a **State** field from City data for geographic analysis

### Geographic Visualization

* Integrated a custom **India States TopoJSON**
* Built an interactive **state-level sales map** in Power BI
